# Data-Day
Hello! We are Nate, Elliot, and Will. Welcome to our 2027 senior design project repository.

### Project Overview
Our project aims to create a system that allows users to build applications for a 64x32 pixel LED display. We will build our own product using a display board and Orange Pi Zero 3. As for the system, we plan to create an open-source library/SDK that will make for simpler development so users can easily create their own applications for the displays. This involves building out custom API methods to abstract boilerplate code from end users, and documenting steps users can follow to build their own applications. Additionally, we aim to build out some demo applications for the product to showcase.
