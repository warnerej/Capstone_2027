## Anticipated Questions

*Answers are drawn from the deck content. Items marked **[confirm]** need a team check before Data-Day.*

| Likely question | Owner | Short answer |
|---|---|---|
| Why an Orange Pi Zero 3? | Will | Orange Pi Zero 3 wasn't our first choice, but we were handcuffed by budget. It is a budget version of a lot of other boards out there. |
| How is this different from existing LED matrix dashboards? | Nate | The main difference is that it is open-source and built around a reusable SDK, so anyone can build apps without writing drivers. It also stays low-cost and minimal. |
| What does the SDK do for developers? | Nate | It abstracts hardware code so developers don't have to write display-driver, timing, or input-handling code. They focus on app functionality. |
| How do apps get onto the device? | Elliot | Apps are uploaded to the device through our network-based server, hosted by the Orange Pi. |
| How do users interact with it? | Elliot | One dial button handles the system-wide input to switch between applications, and the other dial button input can be programmed for each application. |
| How will you manage licensing? | Will | We will comply with the license of every dependency or third-party code and keep the project open-source. |
| What is your biggest risk? | Elliot | Hardware integration, since week 11 was early hardware work toward cohesion. Our end-of-term goal is to validate the hardware early. |
| Can it handle live data like sports scores / weather? | Elliot | Yes, as long as the API is public. The Orange Pi has network capabilities to get live data. |
