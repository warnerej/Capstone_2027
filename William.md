## Co-op Experiences
### LCS (London Computer Systems)
I have spent 4 semesters at LCS and I am currently working there part time. In my first semester (January 2024 - April 2024) I worked as a Quality Assurance Tester Co-op for the API team where I
spent time learning about our API and how it works. I mainly used our in-house test client, HeidiSQL and Postman. Using these tools, I would test the changes that the developers made, analyzing the
differences between the old and new JSON being returned. I learned how to work in an Agile environment, participating in sprints and working closely with the development team. 

Then during my second Co-op semester, (August 2024 - December 2024) I worked as a Software Developer Co-op for the API team. In this role I primarily worked on bug fixes, working with customers 
and their sensitive data to help resolve issues with our API. In this role, I primarily wrote in C# and SQL, building a strong foundation for me to use in the future. I learned how an API worked in-and-out, 
since I was working on new bug fixes that we in separate areas of our codebase. Since I was only working in the backend, I became very used to it and decided to look for another Co-op to expose me to other 
ideas and technologies.

### Paycor
